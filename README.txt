URBAN RIDER 3D - PWA

Files:
- index.html: game
- manifest.webmanifest: PWA install metadata
- sw.js: service worker for app-shell caching
- icons/icon.svg: app icon

INSTALL:
A PWA cannot be installed from file:// directly. Serve this folder from HTTPS or localhost.
Then open index.html through that web server in a supported browser and use the browser's Install/Add to Home Screen option.
